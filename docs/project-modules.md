# Project Modules — Art Gallery Management System

Complete module blueprint for the MCA Final Year project.  
**Planned modules stay in scope** even if not coded yet.

---

## A. Core modules

| Module | Description | Typical status |
| --- | --- | --- |
| Authentication & Authorization | Register, login, logout, JWT, roles, unauthorized page | Implemented |
| Home & Public Website | Home, header, footer, about, featured artworks | Implemented |
| User Management | Admin views users (visitors/artists accounts) | Implemented (list) |
| Artist Management | Admin CRUD for Artist domain profiles | Planned |
| Category Management | Admin CRUD for categories | Planned |
| Artwork Management | Admin CRUD for artworks + images | Planned |
| Exhibition Management | Exhibitions + assign artworks (M:N) | Planned |
| Visitor Inquiry Management | Contact form + admin inquiry handling | UI started / API planned |

---

## B. Planned extended modules

| Module | Description |
| --- | --- |
| Artist User Dashboard | Logged-in artist views/updates own profile & artworks (optional link to Artist entity later) |
| Public Artwork Gallery | Browse/detail pages from API data (frontend explore page exists with mock data) |
| Search and Filtering | Search by artwork, artist, category |

---

## C. Future scope (not in current ER)

- Shopping cart / wishlist
- Reviews and ratings
- Email notifications

- Virtual gallery tour
- Mobile application
- Multi-language support

These must **not** add entities to the current UML/ER unless the project scope is formally expanded.
